怎么装

  1. 在 PiDeck 里打开「设置 → 插件 → 安装插件 → 从 GitHub 链接…」，粘贴卡片上的安装链接。
  2. 安装只是把源码包放进去，不执行仓库里的任何脚本，也不会跑构建。
  3. 装完仍然是禁用状态，要你在插件列表里逐项确认权限后才启用。
收录自己的插件：往 ayuayue/pideck-plugins 提 PR（模板见 templates/）；只想自己分发就在仓库上打 pideck-plugin topic。开发文档见 PiDeck 的 宿主插件开发指南。
