安装

三步装进去，先看清楚它能碰什么

PiDeck 只把源码包放进去：不执行脚本，不跑构建。装完是禁用状态，逐项确认权限后才真正启用。

  1. 01打开 PiDeck → 设置 → PiDeck 插件 → 从 GitHub 链接安装，粘贴仓库里插件的子目录链接。
  2. 02对照 manifest 的权限清单，看每一行白话解释。权限不满就继续禁用，不会影响 PiDeck 本身。
  3. 03启用并授权。授权绑定整包逐文件 sha256，之后改一个字节都要重新扫描、重新授权。

从模板起步

node scripts/new-plugin.mjs my-panel --template sessions --name "我的面板"

三个模板覆盖了最常见的三种形态，复制即可跑通一个能装进 PiDeck 的最小插件。

minimal无权限 浮层 · 读 context、写 storage、订阅 context.changed 事件
sessionssessions.read 整页 · 分页列会话，读活跃分支历史，跳转工作台
networknetwork.https 弹窗 · 只调 manifest 里声明过的 HTTPS 接口，含加载与失败态
