怎么装

  1. 在 PiDeck 打开「设置 → 插件 → 安装插件 → 从 GitHub 链接…」，粘贴复制到的链接。
  2. 安装只把源码包放进去，不执行仓库里的脚本，也不跑构建。
  3. 装完是禁用状态，确认权限后才启用。
