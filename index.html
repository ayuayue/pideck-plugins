PiDeck 插件

收录表来自本仓库的 registry.json；社区来源是 GitHub 上所有打了 pideck-plugin topic 的仓库。社区插件没有人审阅过，装之前请自己看一眼源码。

加载中…

    安装：在 PiDeck 里打开「设置 → 插件 → 安装插件 → 从 GitHub 链接…」，粘贴下面卡片里的链接。安装只是把源码包放进去， 装完仍然是禁用状态，要你在插件列表里逐项确认权限后才启用。

    收录自己的插件：往 ayuayue/pideck-plugins 提 PR（模板见 templates/）；只想自己分发就在仓库上打 pideck-plugin topic。开发文档见 PiDeck 的 宿主插件开发指南。
