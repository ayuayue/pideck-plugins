# 项目便签

给每个项目记几条便签，按项目分开存在插件自己的存储里。

- 形态：`popover`（侧栏那一行旁边就地展开）
- 权限：**无**（只用 `context` + `storage`）
- 图标：`file-text`

## 为什么这么写

- **零权限也是完整插件**：`context.get()` 和 `storage.*` 不需要任何权限声明，所以这个插件装上去不会出现任何授权提示。想做个「只属于我自己」的小工具，这是最低成本的路子。
- **存储键要自己洗**：`storage` 的键名必须匹配 `^[A-Za-z0-9_.-]{1,80}$`，而 `projectId` 的形状不是契约的一部分——这里把它 `replace(/[^A-Za-z0-9_.-]/g, "-")` 之后截断，再拼上 `notes.` 前缀。
- **配额要自己管**：整个插件只有 1 MiB / 200 键。这里每个项目一个键、每项目最多 100 条、单条最多 2000 字符，超了就在界面上说清楚，而不是让 `storage-full` 抛到用户脸上。
- **整段覆盖**：`storage` 没有事务，读改写都在同一个键上；够用，但别指望并发安全。

## 想改的话

- 便签加标签/分组：把 `notes` 的元素从 `{ id, text, at }` 扩成带 `tags` 的对象即可（值只要 JSON 可序列化）。
- 跨项目搜索：`storage.keys()` 拿全部键，再逐个 `get`（注意配额和请求频率：每实例同时最多 2 个在途、每秒最多 20 个）。
